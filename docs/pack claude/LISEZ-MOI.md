# Pack Claude Code — Bénin Health Intelligence Platform

Ce dossier contient tout ce qu'il faut pour piloter la construction avec Claude Code.

## Installation (étape E00)
1. Créez votre dépôt Git `bhip` (vide).
2. Copiez **à la racine** du dépôt : `CLAUDE.md`, `PROGRESS.md`, le dossier `specs/` et le dossier `docs/`.
3. Ouvrez Claude Code dans ce dossier.

## Utilisation
- Donnez une seule consigne à la fois, en copiant l'encadré « Consigne pour Claude Code » de l'étape dans `specs/25-plan-construction.md` (en commençant par E00).
- Claude Code propose un plan, code, teste, écrit un rapport dans `docs/rapports/EXX.md`, puis **s'arrête**.
- Suivez la section « Ce que vous devez tester vous-même » du rapport.
- Si tout fonctionne, écrivez : `validé EXX`. Sinon, décrivez le problème.

## Contenu
- `CLAUDE.md` : règles permanentes lues automatiquement par Claude Code.
- `PROGRESS.md` : suivi des 31 étapes (E00 à E30).
- `specs/` : le cahier des charges complet en Markdown (même contenu que le PDF / Word).
- `docs/rapports/MODELE-RAPPORT.md` : modèle du rapport de fin d'étape.
- `docs/decisions.md` : journal des décisions.
